Bab 1 • Informatika Kelas 9

Penyajian Data Mentah Menjadi Tabel dan Diagram

Pelajari cara mengolah data mentah menggunakan rumus otomatis serta menyajikannya ke dalam diagram interaktif.

A. Konsep Dasar Penyajian Data

Data mentah adalah kumpulan fakta yang belum ditata. Agar informasi lebih mudah dipahami, data dapat dikelompokkan dalam tabel dan divisualisasikan dalam diagram.

Contoh data mentah: 28, 31, 25, 31, 29. Angka tersebut belum menjelaskan siapa, apa yang diukur, dan bagaimana perbandingannya.
Tabel menyusun data dalam baris dan kolom sehingga kategori, jumlah, dan satuan dapat dibandingkan dengan jelas.

Contoh Data Kelas

Kelas Jumlah siswa
9.132
9.230
9.334

B. Pembuatan Tabel & Panduan Rumus (Excel & Google Sheets)

Panduan langkah demi langkah membuat tabel dan mengolah angka secara otomatis.

1. Langkah-Langkah Pembuatan Tabel

Pada Microsoft Excel:

  1. Ketikkan nama kolom pada Baris 1 (Nama, Tugas, Ujian, dst).
  2. Isi data siswa pada baris-baris berikutnya.
  3. Sorot/blok seluruh rentang sel data (A1:F4).
  4. Klik Menu Insert > pilih Table (atau tekan Ctrl + T).
  5. Centang "My table has headers" lalu klik OK.

Pada Google Sheets:

  1. Buka Google Sheets dan isikan data pada lembar kerja.
  2. Blok seluruh data tabel (A1:F4).
  3. Klik menu Format > pilih Alternating Colors (Warna berganti-ganti).
  4. Pilih tema warna tabel lalu klik Selesai.

2. Contoh Visual Tampilan Lembar Kerja (Spreadsheet)

A (Nama) B (Tugas) C (Ujian) D (Rata-Rata) E (Kelulusan) F (Predikat)
Andi 85 90 87.5 Lulus Istimewa
Budi 70 65 67.5 Remidial Reguler
Citra 95 92 93.5 Lulus Istimewa

3. Panduan Rumus & Formula Dasar

SUM (Penjumlahan) =SUM(...)

Menjumlahkan seluruh nilai pada rentang sel tertentu.

=SUM(B2:C2)
AVERAGE (Rata-rata) =AVERAGE(...)

Menhitung nilai rata-rata dari rentang angka.

=AVERAGE(B2:C2)
MAX (Nilai Tertinggi) =MAX(...)

Mencari nilai tertinggi dari rentang sel.

=MAX(D2:D4)
MIN (Nilai Terendah) =MIN(...)

Mencari nilai terendah dari rentang sel.

=MIN(D2:D4)
IF (Logika Tunggal) =IF(kondisi; benar; salah)

Menentukan hasil berdasarkan satu kondisi logika.

=IF(D2>=75; "Lulus"; "Remidial")
IF AND (Semua Syarat Wajib Terpenuhi)

Lulus HANYA JIKA Tugas & Ujian keduanya >= 75.

=IF(AND(B2>=75; C2>=75); "Lulus"; "Remidial")
IF OR (Minimal Salah Satu Terpenuhi)

Istimewa JIKA Tugas ATAU Ujian mencapai angka >= 90.

=IF(OR(B2>=90; C2>=90); "Istimewa"; "Reguler")

BAGIAN 01 • LOGIKA PEMROGRAMAN

Menyusun Langkah Logis: Algoritma, Flowchart & Pseudocode

Sebelum mengetik kode atau menyusun blok program, seorang pemrogram harus merancang alur logika pemecahan masalah terlebih dahulu melalui tiga bentuk representasi baku.

1. Algoritma

Urutan langkah logis, terstruktur, dan sistematis untuk menyelesaikan suatu permasalahan tertentu.

2. Flowchart

Representasi visual alur algoritma menggunakan simbol-simbol grafis standar baku.

3. Pseudocode

Penulisan kode semu menggunakan bahasa manusia sehari-hari disertai kata kunci komputer (INPUT, IF, THEN, PRINT).

Simbol Standar Diagram Alir (Flowchart):

• Terminator (Oval): Mulai (Start) & Selesai (Stop).
• Input / Output (Jajar Genjang): Membaca masukan / Menampilkan hasil.
• Process (Persegi Panjang): Perhitungan / Pengolahan data.
• Decision (Belah Ketupat): Keputusan percabangan logika (Ya / Tidak).
• Subprogram (Persegi Garis Ganda): Pemanggilan fungsi / prosedur terpisah.
• Flowline (Panah): Menunjukkan arah alur eksekusi langkah.

Contoh Alur Flowchart · Penentuan Kelulusan

Siswa dinyatakan "Lulus" jika $Nilai \ge 75$, dan "Belum Lulus" jika $Nilai < 75$.

⬭ Mulai (Start)
↓
▱ Input nilai
↓
◇ Apakah nilai $\ge 75$?
↙ Ya Tidak ↘
▱ PRINT "Lulus"
▱ PRINT "Belum Lulus"
↓
⬭ Selesai (Stop)

Padanan Pseudocode (Kode Semu)

Penulisan kata kunci komputer terstruktur:

START
INPUT nilai
IF nilai >= 75 THEN
    PRINT "Lulus"
ELSE
    PRINT "Belum Lulus"
END IF
STOP

Simulasi Tracing Flowchart Interaktif

Masukkan sebuah angka untuk melihat bagaimana logika flowchart berjalan langkah demi langkah secara visual!

⬭ Start
▱ Input Angka
◇ MOD 2 = 0?
▱ Output Hasil
⬭ Stop
Tekan "Langkah Berikutnya" untuk memulai penelusuran.
BAGIAN 02 • LINGKUNGAN SCRATCH

Pengenalan Antarmuka & Kategori Blok Scratch

Scratch adalah bahasa pemrograman visual berbasis blok yang dikembangkan oleh MIT Media Lab. Pengguna cukup menyusun skrip dengan metode *drag-and-drop* tanpa perlu mengkhawatirkan kesalahan penulisan (*syntax error*).

1. Elemen Utama Antarmuka (User Interface) Scratch

🎭 Stage (Panggung) Area layar tempat Sprite beraksi, bergerak, dan menampilkan visual animasi atau game.
🐱 Sprite (Objek) Karakter atau objek gambar yang dikendalikan oleh susunan blok perintah program.
🎨 Block Palette Panel kumpulan blok perintah yang dikelompokkan berdasarkan warna dan fungsi kategori.
🧩 Script Area (Area Kerja) Lahan tempat Anda menyeret (*drag*) dan menyusun (*drop*) blok-blok logika program.
👗 Costumes & Sounds Tab Menu untuk mengganti tampilan kostum animasi Sprite serta mengedit efek suara.
🚩 Green Flag / Stop Tombol Bendera Hijau untuk menjalankan program dan tombol Merah untuk menghentikan program.

2. 9 Kategori Warna Blok Perintah Scratch

Motion (Gerakan)

Mengatur posisi, arah, dan perpindahan Sprite. Contoh: move 10 steps, turn 15 degrees.

Looks (Tampilan)

Mengatur ucapan gelembung teks, warna, dan kostum. Contoh: say [Halo!] for 2 secs.

Sound (Suara)

Memutar efek suara atau nada musik. Contoh: play sound [Meow] until done.

Events (Kejadian)

Pemicu awal jalannya skrip (*Hat block*). Contoh: when green flag clicked.

Control (Kontrol)

Mengatur perulangan dan kondisi percabangan. Contoh: repeat 10, if ... then ... else.

Sensing (Sensor)

Mendeteksi masukan pengguna / benturan. Contoh: ask [Nama?] and wait, touching mouse-pointer?.

Operators (Operator)

Operasi matematika ($+,-,*,/$) & logika ($>, <, =, AND, OR$). Contoh: (score) > [50].

Variables (Variabel)

Menyimpan nilai data sementara. Contoh: set [skor] to 0, change [skor] by 1.

My Blocks (Blok Saya)

Membuat prosedur / fungsi buatan sendiri (*Custom Blocks*) untuk modularisasi program.

3. Mengenal Forms / Bentuk Fisik Blok Scratch

🧢 Hat Blocks (Topi)

Berpenutup lengkung di atas. Selalu menjadi pemicu paling awal di bagian atas skrip.

when [green flag] clicked
🧩 Stack Blocks (Tumpukan)

Memiliki takik pasang di atas dan di bawah. Digunakan untuk instruksi aksi berurutan.

move (10) steps
🔷 Boolean Blocks (Hexagon / Segi Enam)

Berbentuk segi enam. Menghasilkan nilai Benar/Salah (TRUE / FALSE) untuk syarat percabangan.

< (nilai) > [75] >
🟢 Reporter Blocks (Lonjong / Oval)

Berbentuk oval lonjong. Mengembalikan nilai angka atau teks ke dalam blok lain.

(answer)
🔲 C-Blocks (Mulut C)

Berbentuk seperti huruf C untuk membungkus blok lain di dalamnya (perulangan/kondisi).

repeat (10) [ ... ]
🛑 Cap Blocks (Penutup)

Berpermukaan rata di bawah. Menandai akhir dari eksekusi alur skrip.

stop [all]
BAGIAN 03 • MENTERJEMAHKAN LOGIKA

Transisi Pseudocode ke Pemrograman Visual Scratch

Perhatikan bagaimana susunan logika pada pseudocode diterjemahkan secara langsung menjadi rangkaian blok pada Scratch:

1. Deskripsi Pseudocode

START
  INPUT nilai
  IF nilai >= 75 THEN
      PRINT "Lulus"
  ELSE
      PRINT "Belum Lulus"
  END IF
STOP

2. Padanan Tumpukan Blok Scratch

when [green flag] clicked
ask [Masukkan nilai Anda:] and wait
set [nilai] to (answer)
if < (nilai) >= [75] > then
say [Lulus!] for (2) secs
else
say [Belum Lulus] for (2) secs
stop [this script]
BAGIAN 04 • SUBPROGRAM

Modularisasi Program: Function, Procedure, & My Blocks

Modularisasi adalah teknik memecah program besar menjadi subprogram (modul) kecil agar lebih terstruktur, mudah dikembangkan, dan dapat digunakan kembali (*reusable*).

1. Function (Fungsi)

Modul yang mengembalikan nilai hasil (*return value*) setelah memproses instruksi.
Analogi: Menghitung luas persegi panjang dan memberikan angka jawabannya.

2. Procedure (Prosedur)

Modul yang menjalankan aksi/instruksi tanpa mengembalikan nilai balik.
Analogi: Perintah mencuci piring atau membunyikan klakson.

Membuat Modul Kustom di Scratch dengan "My Blocks" (Blok Saya):

Di Scratch, Anda dapat membuat prosedur buatan sendiri melalui tombol Make a Block pada kategori My Blocks.

define [SapaSiswa (nama)]
→
say (join [Selamat belajar, ] (nama)) for (2) secs
BAGIAN 05 • PUSTAKA & TRANSISI TEKSTUAL

Konsep Library & Matriks Komparasi Blok vs Tekstual

Library (Pustaka) adalah kumpulan modul siap pakai. Pada Scratch, library diwujudkan dalam fitur Add Extension (Tambah Ekstensi) seperti Ekstensi Pen, Music, dan Text-to-Speech. Pada bahasa tekstual seperti Python, pustaka dipanggil memakai perintah import math.

Matriks Perbandingan Sintaksis: Scratch vs Python vs Bahasa C

Konsep Algoritma Visual Blok (Scratch) Bahasa Python (Tekstual) Bahasa C (Tekstual)
Input / Output ask [...] and wait / say [...] input() / print() scanf() / printf()
Variabel Blok set [x] to (3 + 2) x = 3 + 2 int x = 3 + 2;
Percabangan Blok if [...] then ... else if x >= 75: ... else: ... if (x >= 75) { ... } else { ... }
Perulangan Blok repeat (3) / forever for i in range(3): ... for(int i=0; i<3; i++) { ... }

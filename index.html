Penyajian Data Mentah Menjadi Tabel dan Diagram

Pelajari cara mengolah data mentah menggunakan rumus otomatis serta menyajikannya ke dalam diagram interaktif.

A. Konsep Dasar Penyajian Data

Data mentah adalah kumpulan fakta yang belum ditata. Agar informasi lebih mudah dipahami, data dapat dikelompokkan dalam tabel dan divisualisasikan dalam diagram.

Contoh data mentah: 28, 31, 25, 31, 29. Angka tersebut belum menjelaskan siapa, apa yang diukur, dan bagaimana perbandingannya.
Tabel menyusun data dalam baris dan kolom sehingga kategori, jumlah, dan satuan dapat dibandingkan dengan jelas.

Contoh Data Kelas

Kelas Jumlah siswa
9.132
9.230
9.334

B. Pembuatan Tabel & Panduan Rumus (Excel & Google Sheets)

Panduan langkah demi langkah membuat tabel dan mengolah angka secara otomatis.

1. Langkah-Langkah Pembuatan Tabel

Pada Microsoft Excel:

  1. Ketikkan nama kolom pada Baris 1 (Nama, Tugas, Ujian, dst).
  2. Isi data siswa pada baris-baris berikutnya.
  3. Sorot/blok seluruh rentang sel data (A1:F4).
  4. Klik Menu Insert > pilih Table (atau tekan Ctrl + T).
  5. Centang "My table has headers" lalu klik OK.

Pada Google Sheets:

  1. Buka Google Sheets dan isikan data pada lembar kerja.
  2. Blok seluruh data tabel (A1:F4).
  3. Klik menu Format > pilih Alternating Colors (Warna berganti-ganti).
  4. Pilih tema warna tabel lalu klik Selesai.

Diagram membantu kita mengidentifikasi tren, perbandingan, dan proporsi data secara visual.

Algoritma Lanjutan & Fondasi Literasi Digital

Pelajari teknik pemecahan masalah dengan modularisasi program, penggunaan library, transisi pemrograman visual ke tekstual, flowchart & pseudocode, hingga fondasi literasi digital secara interaktif.

TOPIK 01 • HALAMAN 56–63

Modularisasi Program: Function dan Procedure

Modularisasi adalah teknik memecah program besar yang kompleks menjadi subprogram (modul) kecil agar lebih terstruktur, mudah dikembangkan, dan dapat digunakan kembali (reusable).

1. Function (Fungsi)

Modul yang mengembalikan nilai hasil (return value) setelah memproses instruksi.
Analogi: Ibu bertanya berapa jumlah apel di meja, Anto menghitung lalu menjawab "7 buah".

2. Procedure (Prosedur)

Modul yang menjalankan serangkaian instruksi/aksi tanpa mengembalikan nilai balik.
Analogi: Ibu meminta Anto mencuci apel lalu menaruhnya kembali di piring.

# Contoh Implementasi dalam Bahasa Pemrograman Python def hitung_apel(): return 7 # Function dengan return value (mengembalikan nilai 7) def cuci_apel(): print("Apel telah dicuci bersih!") # Procedure tanpa return value
TOPIK 02 • HALAMAN 64–75

Konsep dan Penggunaan Library (Pustaka Program)

Library (Pustaka) adalah kumpulan modul program atau fungsi siap pakai yang disimpan dalam satu wadah sehingga dapat dipanggil dan digunakan berulang kali tanpa perlu menulis kodenya dari nol.

01. Reusability Kode yang telah dibuat dapat digunakan kembali secara fleksibel di berbagai proyek.
02. Abstraction Menyembunyikan kerumitan detail algoritma internal sehingga pemrogram tinggal memakainya.
03. Efficiency Menghemat waktu dan meningkatkan efisiensi proses pembuatan aplikasi.
import math # Menggunakan fungsi sqrt (akar kuadrat) dari library math bawaan Python akar = math.sqrt(16) print(akar) # Hasil Output: 4.0
TOPIK 03 • HALAMAN 76–90

Transisi Pemrograman Visual Blok ke Tekstual

Pemrograman visual berbasis blok (seperti Scratch/Blockly) mengandalkan metode *drag-and-drop* untuk melatih logika berpikir tanpa terbebani kesalahan penulisan (*syntax error*). Pemrograman tekstual (seperti Bahasa C atau Python) digunakan dalam industri profesional untuk kontrol program yang dinamis.

Konsep Algoritma Visual Blok (Scratch) Bahasa C (Tekstual) Python (Tekstual)
Input / Output Blok ask [...] and wait / say [...] scanf() / printf() input() / print()
Variabel Blok set [x] to (3 + 2) int x = 3 + 2; x = 3 + 2
Percabangan Blok if [...] then ... else if (x < y) { ... } else { ... } if x < y: ... else: ...
Perulangan Blok repeat (3) / forever for(int i=0; i<3; i++) { ... } for i in range(3): ...
TOPIK 04 • HALAMAN 91–114

Flowchart, Pseudocode, dan Simulasi Tracing

Flowchart menggambarkan alur langkah logika program secara visual dengan simbol-simbol standar. Pseudocode adalah deskripsi algoritma menggunakan bahasa natural yang terstruktur (seperti INPUT, IF, THEN, ELSE, OUTPUT) untuk merancang program sebelum diketik menjadi kode asli.

Simbol-Simbol Utama Flowchart:
  • • Oval (Terminator): Menyatakan titik Mulai (Start) atau Selesai (Stop).
  • • Jajar Genjang (Input/Output): Menyatakan pembacaan data masukan atau pencetakan keluaran.
  • • Persegi Panjang (Process): Menyatakan proses perhitungan atau pengolahan data.
  • • Belah Ketupat (Decision): Menyatakan keputusan/percabangan logika (Ya / Tidak).
# Contoh Pseudocode Penentuan Bilangan Genap/Ganjil MULAI INPUT angka JIKA (angka MOD 2 = 0) MAKA OUTPUT "Genap" SELAIN ITU OUTPUT "Ganjil" SELESAI_JIKA SELESAI

TOPIK 05 • HALAMAN 119–125

Pemrosesan Data Komputer & Solusi Troubleshoot

Komputer mengolah informasi melalui alur sistematis: Input (Perangkat Masukan) → Proses (CPU & RAM) → Output (Hasil Keluaran), serta disimpan secara permanen pada media Storage (HDD/SSD).

ALU (Arithmetic Logic Unit) Bagian CPU penanggung jawab operasi matematika (+, -, *, /) dan keputusan logika.
CU (Control Unit) Pengendali lalu lintas data dan instruksi program yang dieksekusi oleh sistem komputer.
RAM (Memori Utama) Tempat penyimpanan data sementara berkecepatan tinggi saat aplikasi sedang berjalan.

Panduan Penanganan Permasalahan Komputer Mandiri (Troubleshoot):

• Komputer Bekerja Sangat Lambat: Tutup aplikasi yang tidak terpakai, bersihkan berkas sampah (*temporary files* & *Recycle Bin*).
• Layar Biru Error (BSOD - Blue Screen of Death): Lakukan *restart* komputer, periksa pembaruan *driver* sistem atau RAM.
• Koneksi Internet Tidak Terhubung: Periksa status Wi-Fi/kabel LAN, muat ulang (*restart*) modem atau router jaringan.

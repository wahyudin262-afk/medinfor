Penyajian Data Mentah Menjadi Tabel dan Diagram

Pelajari cara mengolah data mentah menggunakan rumus otomatis serta menyajikannya ke dalam diagram interaktif.

A. Konsep Dasar Penyajian Data

Data mentah adalah kumpulan fakta yang belum ditata. Agar informasi lebih mudah dipahami, data dapat dikelompokkan dalam tabel dan divisualisasikan dalam diagram.

Contoh data mentah: 28, 31, 25, 31, 29. Angka tersebut belum menjelaskan siapa, apa yang diukur, dan bagaimana perbandingannya.
Tabel menyusun data dalam baris dan kolom sehingga kategori, jumlah, dan satuan dapat dibandingkan dengan jelas.

Contoh Data Kelas

Kelas Jumlah siswa
9.132
9.230
9.334

B. Pembuatan Tabel & Panduan Rumus (Excel & Google Sheets)

Panduan langkah demi langkah membuat tabel dan mengolah angka secara otomatis.

1. Langkah-Langkah Pembuatan Tabel

Pada Microsoft Excel:

  1. Ketikkan nama kolom pada Baris 1 (Nama, Tugas, Ujian, dst).
  2. Isi data siswa pada baris-baris berikutnya.
  3. Sorot/blok seluruh rentang sel data (A1:F4).
  4. Klik Menu Insert > pilih Table (atau tekan Ctrl + T).
  5. Centang "My table has headers" lalu klik OK.

Pada Google Sheets:

  1. Buka Google Sheets dan isikan data pada lembar kerja.
  2. Blok seluruh data tabel (A1:F4).
  3. Klik menu Format > pilih Alternating Colors (Warna berganti-ganti).
  4. Pilih tema warna tabel lalu klik Selesai.

2. Contoh Visual Tampilan Lembar Kerja (Spreadsheet)

A (Nama) B (Tugas) C (Ujian) D (Rata-Rata) E (Kelulusan) F (Predikat)
Andi 85 90 87.5 Lulus Istimewa
Budi 70 65 67.5 Remidial Reguler
Citra 95 92 93.5 Lulus Istimewa

3. Panduan Rumus & Formula Dasar

SUM (Penjumlahan) =SUM(...)

Menjumlahkan seluruh nilai pada rentang sel tertentu.

=SUM(B2:C2)
AVERAGE (Rata-rata) =AVERAGE(...)

Menghitung nilai rata-rata dari rentang angka.

=AVERAGE(B2:C2)
MAX (Nilai Tertinggi) =MAX(...)

Mencari nilai tertinggi dari rentang sel.

=MAX(D2:D4)
MIN (Nilai Terendah) =MIN(...)

Mencari nilai terendah dari rentang sel.

=MIN(D2:D4)
IF (Logika Tunggal) =IF(kondisi; benar; salah)

Menentukan hasil berdasarkan satu kondisi logika.

=IF(D2>=75; "Lulus"; "Remidial")
IF AND (Semua Syarat Wajib Terpenuhi)

Lulus HANYA JIKA Tugas & Ujian keduanya >= 75.

=IF(AND(B2>=75; C2>=75); "Lulus"; "Remidial")
IF OR (Minimal Salah Satu Terpenuhi)

Istimewa JIKA Tugas ATAU Ujian mencapai angka >= 90.

=IF(OR(B2>=90; C2>=90); "Istimewa"; "Reguler")

Algoritma Lanjutan & Fondasi Pemrograman

Pelajari teknik pemecahan masalah dengan modularisasi program, penggunaan library, transisi pemrograman visual ke tekstual, flowchart & pseudocode, serta eksplorasi lengkap Scratch interaktif.

TOPIK 01 • HALAMAN 56–63

Modularisasi Program: Function dan Procedure

Modularisasi adalah teknik memecah program besar yang kompleks menjadi subprogram (modul) kecil agar lebih terstruktur, mudah dikembangkan, dan dapat digunakan kembali (reusable).

1. Function (Fungsi)

Modul yang mengembalikan nilai hasil (return value) setelah memproses instruksi.
Analogi: Ibu bertanya berapa jumlah apel di meja, Anto menghitung lalu menjawab "7 buah".

2. Procedure (Prosedur)

Modul yang menjalankan serangkaian instruksi/aksi tanpa mengembalikan nilai balik.
Analogi: Ibu meminta Anto mencuci apel lalu menaruhnya kembali di piring.

# Contoh Implementasi dalam Bahasa Pemrograman Python def hitung_apel(): return 7 # Function dengan return value (mengembalikan nilai 7) def cuci_apel(): print("Apel telah dicuci bersih!") # Procedure tanpa return value
TOPIK 02 • HALAMAN 64–75

Konsep dan Penggunaan Library (Pustaka Program)

Library (Pustaka) adalah kumpulan modul program atau fungsi siap pakai yang disimpan dalam satu wadah sehingga dapat dipanggil dan digunakan berulang kali tanpa perlu menulis kodenya dari nol.

01. Reusability Kode yang telah dibuat dapat digunakan kembali secara fleksibel di berbagai proyek.
02. Abstraction Menyembunyikan kerumitan detail algoritma internal sehingga pemrogram tinggal memakainya.
03. Efficiency Menghemat waktu dan meningkatkan efisiensi proses pembuatan aplikasi.
import math # Menggunakan fungsi sqrt (akar kuadrat) dari library math bawaan Python akar = math.sqrt(16) print(akar) # Hasil Output: 4.0
TOPIK 03 • HALAMAN 76–90

Transisi Pemrograman Visual Blok ke Tekstual

Pemrograman visual berbasis blok (seperti Scratch/Blockly) mengandalkan metode *drag-and-drop* untuk melatih logika berpikir tanpa terbebani kesalahan penulisan (*syntax error*). Pemrograman tekstual (seperti Bahasa C atau Python) digunakan dalam industri profesional untuk kontrol program yang dinamis.

Konsep Algoritma Visual Blok (Scratch) Bahasa C (Tekstual) Python (Tekstual)
Input / Output Blok ask [...] and wait / say [...] scanf() / printf() input() / print()
Variabel Blok set [x] to (3 + 2) int x = 3 + 2; x = 3 + 2
Percabangan Blok if [...] then ... else if (x < y) { ... } else { ... } if x < y: ... else: ...
Perulangan Blok repeat (3) / forever for(int i=0; i<3; i++) { ... } for i in range(3): ...
TOPIK 04 • HALAMAN 91–114

Flowchart, Pseudocode, dan Simulasi Tracing

Flowchart menggambarkan alur langkah logika program secara visual dengan simbol-simbol standar. Pseudocode adalah deskripsi algoritma menggunakan bahasa natural yang terstruktur (seperti INPUT, IF, THEN, ELSE, OUTPUT) untuk merancang program sebelum diketik menjadi kode asli.

Simbol-Simbol Utama Flowchart:
  • • Oval (Terminator): Menyatakan titik Mulai (Start) atau Selesai (Stop).
  • • Jajar Genjang (Input/Output): Menyatakan pembacaan data masukan atau pencetakan keluaran.
  • • Persegi Panjang (Process): Menyatakan proses perhitungan atau pengolahan data.
  • • Belah Ketupat (Decision): Menyatakan keputusan/percabangan logika (Ya / Tidak).
# Contoh Pseudocode Penentuan Bilangan Genap/Ganjil MULAI INPUT angka JIKA (angka MOD 2 = 0) MAKA OUTPUT "Genap" SELAIN ITU OUTPUT "Ganjil" SELESAI_JIKA SELESAI

Simulasi Tracing Flowchart Interaktif

Masukkan sebuah angka untuk melihat bagaimana logika flowchart berjalan langkah demi langkah secara visual!

⬭ Start
▱ Input Angka
◇ MOD 2 = 0?
▱ Output Hasil
⬭ Stop
Tekan "Langkah Berikutnya" untuk memulai penelusuran.
TOPIK 05 • PEMROGRAMAN VISUAL BLOK

E. Pemrograman Visual Scratch: Antarmuka, Kode Blok, & Pembuatan Game

Scratch adalah lingkungan pemrograman visual berbasis blok yang dikembangkan oleh MIT Media Lab. Pada Scratch, pemrograman dilakukan dengan cara menyusun balok-balok kode (*drag and drop*) sehingga mempermudah pemula dalam memahami algoritma tanpa perlu mengkhawatirkan kesalahan penulisan kata (*syntax error*).

1. Mengenal Antarmuka (Interface) Utama Scratch

a. Stage (Panggung Utama)

Layar eksekusi tempat animasi, karakter, dan interaksi program ditampilkan. Stage memiliki sistem koordinat Kartesius: Sumbu X (-240 s/d 240) dan Sumbu Y (-180 s/d 180).

b. Sprite & Backdrop Pane

Area pengelolaan objek karakter (*Sprite*) dan dekorasi gambar latar belakang (*Backdrop*). Di sini kamu bisa menambah, menghapus, atau mengatur posisi awal Sprite.

c. Blocks Palette (Koleksi Kategori Blok)

Kumpulan balok perintah program yang dikelompokkan berdasarkan warna dan fungsi operasionalnya (seperti Motion, Looks, Sound, Events, Control, dll).

d. Scripts Area (Lembar Kerja Kode)

Papan kerja tempat kita menyeret (*drag*) dan menyusun balok-balok perintah menjadi satu skrip algoritma utuh yang saling terhubung.

2. Kategori & Fungsi Berbagai Kode Blok Scratch

⚡ Events (Kuning)

Pemicu berjalannya skrip program.
Contoh: when 🚩 clicked, when key [space] pressed.

🏃 Motion (Biru)

Mengatur posisi & pergerakan Sprite.
Contoh: move 10 steps, turn ↻ 15 deg, go to x:0 y:0.

🎨 Looks (Ungu)

Mengatur tampilan kostum & dialog.
Contoh: say "Halo!", switch costume to [].

🔊 Sound (Pink)

Memutar efek suara dan lagu.
Contoh: play sound [Pop] until done, change volume by -10.

🔄 Control (Oranye)

Mengatur alur logika & perulangan.
Contoh: repeat (10), forever, if ... then.

🎯 Sensing (Cyan)

Mendeteksi sentuhan, kursor, & input.
Contoh: touching [mouse]?, ask [] and wait.

🔢 Operators (Hijau)

Operasi matematika & perbandingan.
Contoh: pick random (1) to (10), (score) > 50.

📦 Variables (Oranye Tua)

Menyimpan data nilai dinamis.
Contoh: set [Skor] to 0, change [Skor] by 1.

3. Game Dasar: "Tangkap Apel (Catching Apple)"

Tujuan Game: Pemain mengontrol mangkok ke kiri-kanan untuk menangkap buah apel yang jatuh acak dari atas. Setiap kali apel tertangkap, skor bertambah 1 poin.

Langkah 1: Menyiapkan Karakter (Sprite) dan Latar (Backdrop)
  • Klik ikon Choose a Sprite > Cari dan pilih Sprite Bowl (Mangkok) dan Apple (Apel).
  • Klik ikon Choose a Backdrop > Pilih tema latar panggung Blue Sky atau Farm.
Langkah 2: Pemrograman Gerakan Mangkok (Sprite Bowl)

Mengatur agar mangkok dapat bergeser ke kanan dan kiri menggunakan tombol panah keyboard:

when 🚩 clicked
forever
  if <key [right arrow v] pressed?> then
    change x by 10
  end
  if <key [left arrow v] pressed?> then
    change x by -10
  end
end
Langkah 3: Pemrograman Jatuhnya Apel & Logika Penambahan Skor (Sprite Apple)

Buat variabel baru bernama Skor pada kategori Variables, lalu susun kode berikut pada Sprite Apple:

when 🚩 clicked
set [Skor v] to 0
forever
  go to x: (pick random (-200) to (200)) y: 180
  repeat until <(y position) < -160>
    change y by -5
    if <touching [Bowl v]?> then
      change [Skor v] by 1
      play sound [Pop v] until done
      go to x: (pick random (-200) to (200)) y: 180
    end
  end
end

4. Game Lanjutan: "Hiu Pemakan Ikan & Hindari Kepiting"

Fitur Tambahan: Speed Up & Game Over

Konsep Utama Game: Pemain mengendalikan Hiu (Shark) untuk berburu Ikan Kecil (Fish) demi mendapat poin. Semakin tinggi poin yang didapatkan, pergerakan Ikan akan semakin cepat (Akselerasi). Namun, Hiu harus berhati-hati menghindari Kepiting (Crab)! Jika Hiu menyentuh Kepiting, game akan langsung Game Over.

Langkah 1: Menyiapkan Objek Karakter & Latar Bawah Laut
  • Pilih Backdrop bertema bawah laut: Underwater 1 atau Underwater 2.
  • Tambah Sprite Hiu utama: Shark2.
  • Tambah Sprite Makanan: Fish.
  • Tambah Sprite Musuh/Rintangan: Crab (Kepiting).
Langkah 2: Pemrograman Pergerakan Hiu (Sprite Shark2)

Buat Hiu bergerak mulus mengikuti posisi kursor mouse pemain:

when 🚩 clicked
forever
  point towards [mouse-pointer v]
  move (5) steps
end
Langkah 3: Pemrograman Ikan Kecil (Poin & Akselerasi Kecepatan Otomatis)

Buat dua buah variabel baru: Skor dan Kecepatan Ikan. Ketika Skor mencapai 5 poin, kecepatan bertambah ke 8, dan saat mencapai 15 poin, kecepatan bertambah ke 12. 

when 🚩 clicked
set [Skor v] to 0
set [Kecepatan Ikan v] to 4
show
forever
  move (Kecepatan Ikan) steps
  if on edge, bounce
  
  if <(Skor) > 5> then
    set [Kecepatan Ikan v] to 8
  end
  if <(Skor) > 15> then
    set [Kecepatan Ikan v] to 12
  end
  
  if <touching [Shark2 v]?> then
    change [Skor v] by 1
    play sound [Bite v] until done
    go to (random position v)
  end
end
Langkah 4: Pemrograman Kepiting (Rintangan Musuh & Game Over)

Kepiting akan berjalan patroli secara acak. Jika menyentuh Hiu, Kepiting akan menampilkan pesan "Game Over!" dan menghentikan seluruh permainan. 

when 🚩 clicked
show
forever
  move (3) steps
  turn ↻ (pick random (-15) to (15)) degrees
  if on edge, bounce
  
  if <touching [Shark2 v]?> then
    play sound [Oops v] until done
    say [GAME OVER! Kamu Menabrak Kepiting!] for (2) seconds
    stop [all v]
  end
end
